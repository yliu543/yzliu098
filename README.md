## Terminal Steps for Creating a Repository
    #You will have to do these steps for EVERY new project you wish to push to GitHub
    Open the terminal and make sure it is in the correct directory → pwd
    Initialize repo, tell gitbash to track. Creates repo ONLY on local.
    Terminal Command: git init → git initialize
    Create the online repo to connect with. Go to github.com → click new repo
    Give it a name and hit Create Repository
    Copy git remote add origin command and paste in vsc terminal and hit enter
